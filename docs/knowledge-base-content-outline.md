# 量智启学：面向学习者的知识库内容大纲

> 版本：框架稿 v0.1  
> 用途：指导团队手工整理前台文章，并为后续 RAG 文档入库提供统一结构。  
> 原则：先直觉、再定义；先观察、再公式；每一节尽量与游戏或可执行实验形成连接。

## 一、推荐内容结构

### 01 先看见全景

1. 量子计算究竟是什么？
2. 经典比特与量子比特
3. 你的量子学习地图

目标：降低陌生感，建立“量子计算只在特定问题上有优势”的正确预期。

### 02 建立核心直觉

1. 叠加不是“同时发生”
2. 看不见的相位，如何制造干涉
3. 测量：从可能到结果
4. 在布洛赫球上看见量子态

目标：让学习者能够用自己的话解释振幅、相位、干涉、测量和采样之间的关系。

### 03 读懂量子线路

1. X、Z、H：三扇基础量子门
2. 多比特系统与 CNOT
3. 亲手制备一个 Bell 态
4. 像读乐谱一样读量子线路

目标：从单比特操作过渡到多比特联合状态，并能阅读简单线路图。

### 04 走近量子算法

1. Deutsch–Jozsa：一次提问的优势
2. Grover 搜索：放大正确答案
3. VQE 与 QAOA：让经典和量子协作
4. Shor 算法为什么改变密码学

目标：不要求背代码，重点回答“问题是什么、量子步骤利用了什么、优势与限制是什么”。

### 05 开始动手实践

1. Qiskit 第一步
2. 运行你的第一个 Bell 线路
3. 噪声、保真度与真实量子计算机

目标：让学习者完成从线路构建、模拟执行到阅读结果的一次完整实践。

### 06 回到游戏验证

1. 《量子小丑牌》概念图鉴
2. 坍塌轮盘背后的测量
3. 《量子魔法师》术式映射

目标：把牌、术式、计分与概率反馈翻译回正式量子概念，形成“体验—解释—再验证”闭环。

## 二、每篇文章的固定写作模板

1. **学习问题**：用一句真实困惑开场。
2. **预计用时与难度**：建议控制在 8—25 分钟。
3. **学习目标**：写 2—4 条可验证的目标，使用“解释、区分、预测、构建”等动词。
4. **无公式直觉**：先用图像、动作或日常类比解释。
5. **标准定义**：补充严谨术语；有必要时再放公式。
6. **类比边界**：说明常见类比在哪些地方会失效。
7. **最小示例**：一张线路图、一段短代码或一个可重复的小实验。
8. **游戏关联**：指出对应关卡、手牌、术式或反馈指标。
9. **常见误区**：列出 2—3 个易混点。
10. **自测与延伸**：3 道轻量自测题和 1 个下一步入口。
11. **来源与审校**：记录资料出处、审校人和最后更新时间。

## 四、内容治理建议

- 用户前台文章与 RAG 原始资料分层：前者强调教学叙事，后者保留完整来源和可检索片段。
- 每篇文章使用唯一 `id`，后续可直接关联问答引用、学习进度和游戏关卡。
- 正式内容至少经过一次量子专业审校；公式、代码应注明框架版本。
- 优先使用官方文档、开放课程、公开论文和明确授权素材。
- 避免把“量子并行”写成“同时试完所有答案”等容易造成误解的绝对表述。
- 文章发布状态建议使用：`框架`、`初稿`、`已审校`、`已发布`。
