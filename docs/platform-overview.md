# 量智启学平台介绍与当前功能

核对日期：2026-10-14。功能基线：`e69f3e6`，分支：`codex/learner-platform-ui`。
本文依据当前平台预览、源码与接口实测编写；历史开发计划不能直接作为完成证明。

## 一分钟介绍

量智启学是一个面向初学者的量子计算学习平台，把学习资料、学习路径、量子线路实验、小游戏和 AI 伴学放在同一个网站中。学习者可以先通过短篇资料建立直觉，再搭建线路观察量子门的作用，或通过游戏进行练习。平台也已经具备学习记录、概念掌握度估计和下一步推荐的基础能力。

当前已经形成可运行的教学原型：六阶段、21个主题的学习目录中有5篇示例文章；线路实验室支持自由搭建和5个引导任务；同学开发的“小黑天天上夜班”网站和轻量试玩已经接入。AI检索库在本机包含36份文档、289个向量片段。真实模型回答仍需配置服务密钥，教学内容及检索质量还需要扩充和评测。

## 资料库和向量库有什么区别

资料库面向学习者，回答“我应该读什么”，使用前端教学文章模型组织内容。
检索语料库面向AI问答，回答“模型可以依据哪些资料”，来源为 `docs/quantum/`。
两者并不是同一个数量：5篇可读示例文章、36份检索文档、289个索引片段分别对应不同对象。

构建资料索引时，后端会发现文档、切块、计算向量，并存入本地SQLite索引；检索阶段结合向量相似度和关键词排序。当前默认使用 `hashing` 嵌入与 `hybrid` 检索，不能表述为已经上线经过评测的高质量语义嵌入。现有广泛主题问题仍可能召回偏题段落，需要评测召回与重排效果。

`GET /api/rag/index-status` 返回实际索引数量与检索配置，不返回本机路径或密钥。换一台电脑后需要重新构建索引，289不是随代码上传的固定数据库。

## 多智能体部分的准确介绍

已经实现职责分工的RAG流水线：识别任务与召回资料 → 重排、去重和资料质量检查 → 依据片段生成回答 → 检查引用与基本格式 → 必要时修正一次。

检索、校验和审查主要使用算法及规则，生成和修正调用配置的大模型。当前审查不是专家级量子理论验证；通过审查不代表答案一定正确，confidence也不是经校准的正确概率。

当前整合版本的AI页面调用 `POST /api/rag/ask`，请求完成后展示阶段结果。旧工作区曾实现的 `/rag/ask/stream` 尚未迁入此分支，不能把历史流式原型说成当前已提供的实时阶段输出。

## 建议的现场演示顺序

1. 首页：说明阅读、实验、游戏三种学习方式。
2. 资料库：搜索“测量”，观察筛出对应文章，再打开文章与小测。
3. 学习路径：展示六阶段与“先学什么”的关系；未登录时展示通用路径。
4. 线路实验室：点击Bell预设，再运行线路，展示 `00`、`11` 各50%的测量概率和对应代码。
5. 游戏页：展示同学的小黑网站与维修试玩，说明微信小游戏码还待接入。
6. 知识来源：展示36份语料、来源链接和289个索引片段。
7. AI与档案：说明其已有架构与当前限制；没有密钥时不要把模型回答作为现场成功演示项。
8. 如需要展示评估，明确这是流程演示，而不是教学有效性的研究结果。
