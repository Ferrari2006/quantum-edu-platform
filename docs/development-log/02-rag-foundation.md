# 阶段02：RAG基础链路与知识来源

## 阶段目标

建立量子计算垂直知识库的基础处理链路，使系统能够读取资料、分块、索引、检索并向用户返回可追溯的来源。

## 主要成果

- 支持Markdown和纯文本资料发现与读取；
- 支持文档清洗和分块；
- 建立关键词检索、向量检索和混合检索；
- 建立本地SQLite向量索引；
- 返回文档编号、片段编号、标题、来源和检索分数；
- 建立arXiv、OpenAlex等论文元数据处理基础；
- 保留只检索接口和完整问答接口。

## 重要决策

- `docs/quantum/`作为专业检索语料目录；
- 默认采用混合检索，避免只依赖语义向量或只依赖关键词；
- 论文来源先处理元数据和允许使用的摘要，不自动绕过版权限制下载全文；
- 未配置大模型密钥时，纯检索仍可运行。

## 已知限制

- 当前权威语料规模仍小；
- Qiskit资料版本管理和定期更新尚未自动化；
- 尚未形成覆盖量子计算主要主题的离线检索评测集。
