# 阶段01：平台整合与学习者知识库

## 阶段目标

把原有游戏原型、后端服务和前端页面整合为统一的“量智启学”平台，并搭建面向学习者的知识库框架。此阶段重点是页面结构、目录、交互和内容大纲，不追求一次性填满全部教学内容。

## 主要成果

- 建立FastAPI后端与Vite/React前端的统一项目结构；
- 将两套量子游戏源码保留在`games/game1`和`games/game2`，通过统一游戏API桥接到平台；
- 建立知识库首页、六阶段学习路径和21个主题目录；
- 完成站内搜索、收藏、完成状态、学习进度和文章导航；
- 添加账号、登录和用户学习记忆；
- 建立中英文公共界面；
- 提供人工整理内容使用的知识库大纲。

## 重要决策

- 学习者阅读内容与RAG原始语料分层维护：前者强调教学体验，后者强调检索质量和来源信息；
- 游戏源码保持模块独立，平台通过适配层复用其状态与计算逻辑；
- 收藏和学习进度初期保存在浏览器本地，后续再迁移到用户数据库。
