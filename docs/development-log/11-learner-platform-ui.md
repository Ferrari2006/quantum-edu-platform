## 本轮实现

- 新首页以阅读、实验、游戏串联学习体验；统一深绿色、浅绿色强调色、字号、卡片、留白、按钮和焦点反馈。
- `/resources`：关键词搜索、学习阶段筛选、可阅读文章与待补充主题区分。
- `/path`：六阶段地图；登录后调用学习推荐；连接文章、前后测演示及引导实验。
- `/sources`：构建时扫描真实语料，展示标题、来源、原始链接、记录日期、版本和许可字段；不虚构未登记信息。
- `GET /api/rag/index-status`：返回实际索引片段数、嵌入模型、检索模式和就绪状态，不暴露路径和密钥。
- 本地36份语料已经构建289个向量片段；使用hashing嵌入和hybrid检索，已走通实际召回。
- 建立隔离的本机后端依赖，恢复FastAPI服务。依赖位于本机临时目录，启动时通过`QUANTUM_RUNTIME_PATH`指定，不提交Git。
- 安装官方Playwright skill，用真实浏览器核对桌面与390px手机宽度，以及资料搜索。
