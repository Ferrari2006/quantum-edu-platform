## 维护规则

每个开发阶段至少记录以下内容：

1. 阶段目标和需求来源；
2. 修改的模块和核心文件；
3. 重要架构决策及原因；
4. 实际验证方式和结果；
5. 已知限制与未完成事项；
6. 对应分支、提交或Pull Request；
7. 下一阶段建议。

开发记录不得保存API Key、账号口令、访问令牌、个人隐私数据或其他敏感信息。
