# 阶段08：学习档案与前置概念推荐

## 阶段目标

让已经采集的阅读、小测、实验和游戏证据真正对学习者可见，并把“推荐某篇文章”升级为“说明为什么推荐、前置概念是否具备、可以立即做什么”。

## 主要成果

### 学习档案页面

- 新增`/#/progress`学习档案入口，并加入全局导航和平台首页；
- 展示平均掌握度、已覆盖概念、熟练概念数和学习证据总数；
- 展示最多6条个性化下一步行动；
- 展示已有概念的掌握度进度条、证据数量和熟练等级；
- 支持“全部 / 需要巩固 / 已经熟练”筛选；
- 展示最近50条文章、小测、实验和游戏学习记录；
- 支持手动刷新和导出个人学习数据JSON；
- 未登录、加载中、加载失败和无数据均有明确状态；
- 知识库首页新增“查看完整学习档案”入口。

### 前置概念与行动推荐

- 为课程建立第一版无环前置概念关系；
- 以55%掌握度作为“已具备基础”的MVP阈值；
- 推荐顺序优先考虑薄弱概念，再考虑前置条件已经满足的新概念；
- 当前置条件不足时，返回缺失概念名称并解释原因；
- 每条推荐返回可执行动作：阅读文章、进入线路实验室、进入游戏实验场或让AI分步讲解；
- 掌握度分为`mastered`、`developing`和`needs_review`三个等级；
- 学习时间线由后端补充概念标题，避免前端只展示内部ID。

## 推荐示例

以Bell态为例，推荐关系为：

```text
经典比特与量子比特
        ↓
      叠加态
        ↓
   单量子比特门
        ↓
 多比特门与 CNOT
        ↓
     Bell 态
```

当学习者尚未掌握CNOT时，系统可以显示Bell态主题，但会明确建议先补齐“多比特门与CNOT”；满足前置条件后，则改为推荐阅读Bell态并进入线路实验室验证。

## 已知限制

- 前置概念图目前由项目团队人工维护，尚未提供教师可视化编辑器；
- 55%、75%等阈值属于MVP启发式参数，需用真实学习数据校准；
- 学习时间线目前只提供最近50条，没有分页和时间范围筛选；
- 导出格式为原始JSON，尚未提供适合教师阅读的PDF或表格报告；
- 个人档案面向单个用户，尚未实现班级或团队视图。

## 下一阶段建议

- 增加教师端课程、题库与前置概念管理；
- 增加学习时间线分页和按证据类型筛选；
- 增加每周学习摘要和阶段目标；
- 将掌握度变化做成趋势图，而不只显示当前值；
- 根据推荐结果直接预填线路实验或AI伴学任务。
