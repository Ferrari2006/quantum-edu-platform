# 1.5.1 矩阵的特征值与特征向量

# 1.5.2 Hermite矩阵

​ 定义 1.5.3 若矩阵 _B_ 中的每个元素都是矩阵 _A_ 中相应元素的共轭，则称矩阵 _B_ 是矩阵 _A_ 的共轭矩阵，将 _B_ 记作 _A_ * 。

# 1.5.3 对易式与反对易式
