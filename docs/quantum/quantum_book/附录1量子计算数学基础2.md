# 1.3 向量空间

​ 学习量子计算，要对量子力学有所了解，而量子力学是由希尔伯特空间来描述的，希尔伯特空间又是向量空间，因此首先要来介绍向量空间（vector spaces）[2,4,6,8]。

​ 向量空间本质上是一个由向量组成的集合，然后引进一些运算规则。那什么是向量呢？向量相对数量来说的，数量是只有大小的量，而向量不仅有大小而且还有方向的量。有时，向量也称为矢量。可以认为向量是数量的一个自然的扩充。

​ 假设有一个数域 _K_ （集合 _K_ 中任意两个元素的和、差、积、商（除数不为0）还属于集合 _K_ ，称该集合为数域 _K_ ），自然想到用直积将数域 _K_ 进行扩充，n个数域 _K_ 的直积可以表示为

_K_ _n_ = {(_v_ 1,  _v_ 2, ⋯,  _v_ _n_) ∣  _v_ _i_ ∈  _K_ ,  _i_ = 1, 2, ⋯,  _n_}

​ 其中 _K_ _n_ 元素 (_v_ 1,  _v_ 2, ⋯,  _v_ _n_) 称为 _n_ 维向量，称 _v_ _i_ 为其第 _i_ 个分量。为了表示方便与统一将带小括号的元素 (_v_ 1,  _v_ 2, ⋯,  _v_ _n_) 记作列向量, 即:

(_v_ 1,  _v_ 2, ⋯,  _v_ _n_) : = ⎡⎢⎢⎢⎢⎢⎣ _v_ 1 _v_ 2 ⋮  _v_ _n_ ⎤⎥⎥⎥⎥⎥⎦

​ 在数学上，向量常用加粗的小写拉丁字母 **a, b, c, ……** 或者带箭头的小写拉丁字母 → _a_ , → _b_ , → _c_ , … 来表示。而在量子物理上，常用带有狄拉克符号 (|*⟩) 的字母 |_a_ ⟩ , |_b_ ⟩ , |_c_ ⟩ , … 来表示。这里统一采用带有狄拉克符号的表示方法，即:

|_v_ ⟩ : = (_v_ 1,  _v_ 2, ⋯,  _v_ _n_) : = ⎡⎢⎢⎢⎢⎢⎣ _v_ 1 _v_ 2 ⋮  _v_ _n_ ⎤⎥⎥⎥⎥⎥⎦

​ 两个向量 |_u_ ⟩ 、 |_v_ ⟩ 相等的定义为向量的分量分别对应相等，即：

|_u_ ⟩ = |_v_ ⟩ ⇔ ⎡⎢⎢⎢⎢⎢⎣ _u_ 1 _u_ 2 ⋮  _u_ _n_ ⎤⎥⎥⎥⎥⎥⎦ = ⎡⎢⎢⎢⎢⎢⎣ _v_ 1 _v_ 2 ⋮  _v_ _n_ ⎤⎥⎥⎥⎥⎥⎦ ⇔  _u_ 1 =  _v_ 1,  _u_ 2 =  _v_ 2, ⋯,  _u_ _n_ =  _v_ _n_

​ 其中  ⟺  表示"等价于"。 规定 _K_ _n_ 中任意两向量 |_u_ ⟩ 、 |_v_ ⟩ 的加法运算为两向量对应分量分别做普通加法，即：

|_u_ ⟩ + |_v_ ⟩ = ⎡⎢⎢⎢⎢⎢⎣ _u_ 1 _u_ 2 ⋮  _u_ _n_ ⎤⎥⎥⎥⎥⎥⎦ \+ ⎡⎢⎢⎢⎢⎢⎣ _v_ 1 _v_ 2 ⋮  _v_ _n_ ⎤⎥⎥⎥⎥⎥⎦ : = ⎡⎢⎢⎢⎢⎢⎣ _u_ 1 \+  _v_ 1 _u_ 2 \+  _v_ 2 ⋮  _u_ _n_ \+  _v_ _n_ ⎤⎥⎥⎥⎥⎥⎦

规定数量 _k_ ∈  _K_ 与向量 |_u_ ⟩ ∈  _K_ _n_ 之间的数乘运算为数量 _k_ `_与_ : _math_ : `|_u_ ⟩ 的每一个分量分别做普通乘法，即：

_k_ |_u_ ⟩ : = ⎡⎢⎢⎢⎢⎢⎣ _k_ _u_ 1 _k_ _u_ 2 ⋮  _k_ _u_ _n_ ⎤⎥⎥⎥⎥⎥⎦

​ 设 _V_ ≡  _K_ _n_ ， 根据数域的性质，可以验证，对任意的 |_u_ ⟩ , |_v_ ⟩ , |_w_ ⟩ ∈  _V_ ，任意的 _α_ ,  _β_ ∈  _K_ 满足以下运算法 则

(1) |_u_ ⟩ + |_v_ ⟩ = |_v_ ⟩ + |_u_ ⟩ ；（加法交换律）

(2) (|_u_ ⟩ + |_v_ ⟩) + |_w_ ⟩ = |_u_ ⟩ + (|_v_ ⟩ + |_w_ ⟩) ; (加法结合律)

(3) V 中有一个元素 (0, 0, ⋯, 0) ，记作 |0̂⟩ .它满足

|0̂⟩ + |_v_ ⟩ = |_v_ ⟩ + |0̂⟩ = |_v_ ⟩, ∀|_v_ ⟩ ∈  _V_

​具有该性质的元素 |0̂⟩ 称为V的零向量 (zero-vector) ;

(4) 对于 |_v_ ⟩ ∈  _V_ 存在  |‒ _v_ ⟩ : = [ −  _v_ 1 −  _v_ 2 ⋮ −  _v_ _n_ ] ∈  _V_ , 使得

|_v_ ⟩ + |‒ _v_ ⟩ = |0̂⟩ 

​具有该性质的元素 |‒ _v_ ⟩ 称为 |_v_ ⟩ 的负向量 (inverse)；

(5) 1|_v_ ⟩ = |_v_ ⟩ , 其中 1 是 _K_ 的单位元;

(6) (_α_ _β_)|_v_ ⟩ =  _α_(_β_ |_v_ ⟩) ;

(7) (_α_ \+  _β_)|_v_ ⟩ =  _α_ |_v_ ⟩ +  _β_ |_v_ ⟩ ;

(8) _α_(|_u_ ⟩ + |_v_ ⟩) =  _α_ |_u_ ⟩ +  _α_ |_v_ ⟩ 。

​ 数域 _K_ 上所有n元有序数组组成的集合 _K_ _n_ ，再加上定义在其上的加法运算和数乘运算，以及满足的 8 条运算法则一起，称为数域 _K_ 上的一个n维向量空间。 在 _V_ 中，可以根据向量的加法运算来定义向量的减法运算为

|_u_ ⟩ − |_v_ ⟩ : = |_u_ ⟩ + |‒ _v_ ⟩ 

​ 在 _V_ 上，定义加法运算和数乘运算之后，满足的8条运算法则可以推导出向量空间的一些其他性质：

性质1: _V_ 中零向量是唯一的。

性质2: _V_ 中每个向量 _α_ 的负向量是唯一的。

性质3: 0|_v_ ⟩ = |0⟩, ∀|_v_ ⟩ ∈  _V_ 。

性质4: _α_ |0⟩ = |0⟩, ∀ _α_ ∈  _K_ 。

性质5: 如果 _α_ |_v_ ⟩ = |0⟩ ，那么 _α_ = 0 或 |_v_ ⟩ = |0⟩ 。

性质6: ( − 1)|_v_ ⟩ = − |_v_ ⟩, ∀|_v_ ⟩ ∈  _V_ 。

​若 _K_ _n_ 的一个非空子集 _U_ 满足以下两条性质：

(1) |_u_ ⟩, |_v_ ⟩ ∈  _U_ ⇒ |_u_ ⟩ + |_v_ ⟩ ∈  _U_ ,

(2) |_u_ ⟩ ∈  _U_ ,  _k_ ∈  _K_ ⇒  _k_ |_u_ ⟩ ∈  _U_ ,

​ 则称 _U_ 为 _K_ _n_ 的一个线性子空间，简称为子空间 (subspace)。

# 1.3.1 线性无关与基

​ 若想研究数域 _K_ 上向量空间V的结构特征，根据向量空间的定义，只能从V的向量的加法以及数乘这两种运算开始。对于V中的一组向量 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} ，数域 _K_ 中的一组元素 {_α_ 1,  _α_ 2, ⋯,  _α_ _s_} ，作数乘和加法得到

_α_ 1|_v_ 1⟩ +  _α_ 2|_v_ 2⟩ + ⋯ +  _α_ _s_ |_v_ _s_ ⟩ 

​ 根据V中加法和数乘的封闭性， _α_ 1|_v_ 1⟩ +  _α_ 2|_v_ 2⟩ + ⋯ +  _α_ _s_ |_v_ _s_ ⟩ 还是V中的一个向量, 称该向量是 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} 一个线性组合 (linear combination)， {_α_ 1,  _α_ 2, ⋯,  _α_ _s_} 称为系数。 为了方便，像 {_α_ 1,  _α_ 2, ⋯,  _α_ _s_} 这样按照一定顺序写出的有限多个向量称为 _V_ 的一个向量组。 如果 V中的一个向量 |_u_ ⟩ 可以表示成向量组 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} 的一个线性组合, 即：

|_u_ ⟩ =  _s_ ∑ _i_ = 1 _α_ _i_ |_v_ _i_ ⟩ 

​ 那么称 |_u_ ⟩ 可以由向量组 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} 线性表示(或线性表出)。 若向量组 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} 中至少存在一个向量可以由除自身外的其他向量线性表示, 则称这组向量线性相关 (linearly dependent)。否则, 向量组 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} 中任意一个向量都不可以由其他向量线性表示，则称这组向量线性无关 (linearly independent)。 若向量空间V中的任意向量都可以由向量组 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _s_ ⟩} 线性表示, 则称该向量组为向量空间 V的生成集 (spanning set)。 线性无关的生成集称为极小生成集。向量空间的极小生成集定义为向量空间的基，极小生成集中向量的个数定义为向量空间的维数。比如，当数域 _K_ 为复数域 _C_ 时，向量空间 _C_ 2 的基为由向量

|_b_ 1⟩ : = ⎡⎢⎣ 1  0  ⎤⎥⎦, |_b_ 2⟩ = ⎡⎢⎣ 0  1  ⎤⎥⎦

​组成的集合。因为向量空间 _C_ 2 中的任意向量

|_u_ ⟩ = ⎡⎢⎣ _u_ 1 _u_ 2 ⎤⎥⎦

​ 都可以写成向量组 {|_b_ 1⟩ |_b_ 2⟩} 的线性组合，即：

|_u_ ⟩ =  _u_ 1|_b_ 1⟩ \+  _u_ 2|_b_ 2⟩

​ 并且向量组 {|_b_ 1⟩, |_b_ 2⟩} 线性无关。

​​ 因此，当知道向量空间的基时，就可以来用它们来线性表示该向量空间中的任意的向量。也可以说这组基张成了这个向量空间。

​ 然而需要注意的是向量空间的基并不唯一。比如，一组向量

|_b_ 1⟩ : = (1)/(√(2))⎡⎢⎣ 1  1  ⎤⎥⎦, |_b_ 2⟩ = (1)/(√(2))⎡⎢⎣ 1  − 1  ⎤⎥⎦

​ 就可以作为向量空间 _C_ 2 的另一组基。因为向量空间 _C_ 2 中的任意向量

|_u_ ⟩ = ⎡⎢⎣ _u_ 1 _u_ 2 ⎤⎥⎦

​ 可以写成 |_b_ 1⟩ 与 |_b_ 2⟩ 的线性组合

|_u_ ⟩ = (_u_ 1 \+  _u_ 2)/(√(2))|_b_ 1⟩ \+ (_u_ 1 −  _u_ 2)/(√(2))|_b_ 2⟩

​ 假设给定 _n_ 维向量空间 _V_ 的基 {|_b_ 1⟩, |_b_ 2⟩, ⋯, |_b_ _n_ ⟩} 和任意向量 |_u_ ⟩ , 该向量都可以由该基线性表示，即

|_u_ ⟩ =  _α_ 1|_b_ 1⟩ \+  _α_ 2|_b_ 2⟩ \+ ⋯ +  _α_ _n_ |_b_ _n_ ⟩

​ 将 |_u_ ⟩ 在该基 {|_b_ 1⟩, |_b_ 2⟩, ⋯, |_b_ _n_ ⟩} 下的系数称为 |_u_ ⟩ 在该基下的坐标表示, 可以写成列向量的形式，即

|_u_ ⟩ = ⎡⎢⎢⎢⎢⎢⎣ _α_ 1 _α_ 2 ⋮  _α_ _n_ ⎤⎥⎥⎥⎥⎥⎦

​ 从二维复向量空间的例子可以看出，同一个向量在不同的基下有着不同的坐标表示。

​ **定理** 在 n 维向量空间中， 给定一个基, 向量空间中的任意向量的坐标表示是唯一的。 证明设 {|_b_ 1⟩, |_b_ 2⟩, ⋯, |_b_ _n_ ⟩} 为n维向量空间的一个基，根据基的定义，任意向量 |_u_ ⟩ 都可以由这组基线性表示，即

|_u_ ⟩ =  _α_ 1|_b_ 1⟩ \+  _α_ 2|_b_ 2⟩ \+ ⋯ +  _α_ _n_ |_b_ _n_ ⟩

​ 假设 |_u_ ⟩ 在该基下的坐标表示是不唯一的，因此，存在另一种线性表示方式，即：

|_u_ ⟩ = ‒ _α_ 1|_b_ 1⟩ \+ ‒ _α_ 2|_b_ 2⟩ \+ ⋯ + ‒ _α_ _n_ |_b_ _n_ ⟩

​ 将这两个不同的坐标表示的向量做差，得到

|_u_ ⟩ − |_u_ ⟩ = (_α_ 1 − ‒ _α_ 1)|_b_ 1⟩ \+ (_α_ 2 − ‒ _α_ 2)|_b_ 2⟩ \+ ⋯ + (_α_ _n_ − ‒ _α_ _n_)|_b_ _n_ ⟩

即

|0̂⟩ = (_α_ 1 − ‒ _α_ 1)|_b_ 1⟩ \+ (_α_ 2 − ‒ _α_ 2)|_b_ 2⟩ \+ ⋯ + (_α_ _n_ − ‒ _α_ _n_)|_b_ _n_ ⟩

​ 因为基是线性无关的，所以有

_α_ _i_ − ‒ _α_ _i_ = 0,  _i_ = 1, 2, ⋯,  _n_

​ 即：

_α_ _i_ = ‒ _α_ _i_ ,  _i_ = 1, 2, ⋯,  _n_

​ 从而假设不成立，因此在给定基下，任意给定向量的坐标表示唯一。

# 1.3.2 向量的内积

​ 向量的内积是一个从向量空间 _V_ × _V_ 到数域 _K_ 的一个映射 ( − , − ) , 并满足以下性质:

​ 1、映射 ( − , − ) 对第二项是线性的，即：

(|_u_ ⟩,  ∑ _i_ _λ_ _i_ |_v_ _i_ ⟩) =  ∑ _i_ _λ_ _i_(|_u_ ⟩, |_v_ _i_ ⟩)

​ 2、交换共轭性，即：

(|_u_ ⟩, |_v_ ⟩) = (|_v_ ⟩, |_u_ ⟩)*

​ 3、自内积非负性，即：

(|_v_ ⟩, |_v_ ⟩) ≥ 0 

​ 等号成立当且仅当 |_v_ ⟩ 为零向量 |0̂⟩ 。 比如，在 n 维复向量空间中，定义内积为

(|_u_ ⟩, |_v_ ⟩) : =  ∑ _i_ _u_ *_i_ _v_ _i_

​ 其中

|_u_ ⟩ = ⎡⎢⎢⎢⎢⎢⎣ _u_ 1 _u_ 2 ⋮  _u_ _n_ ⎤⎥⎥⎥⎥⎥⎦, |_v_ ⟩ = ⎡⎢⎢⎢⎢⎢⎣ _v_ 1 _v_ 2 ⋮  _v_ _n_ ⎤⎥⎥⎥⎥⎥⎦

​ 在量子力学中，内积 (|_u_ ⟩, |_v_ ⟩) 的标准符号为 ⟨ _u_ ∣  _v_ ⟩ ，即：

⟨ _u_ ∣  _v_ ⟩ : = (|_u_ ⟩, |_v_ ⟩) 

​ 这里 |_u_ ⟩, |_v_ ⟩ 均为内积空间中的向量，符号 ⟨ _u_ | 表示向量 |_u_ ⟩ 的对偶向量 (dual vector)，

⟨ _u_ | : = [_u_ *1,  _u_ *2, ⋯,  _u_ *_n_]

​​ 将拥有内积的空间称为内积空间（inner product space）。量子力学中常提到希尔伯特空间（Hilbert space），在有限维的情况下，希尔伯特空间与内积空间是一致的。无限维的情况，这里不加考虑。

​ 若向量 |_u_ ⟩ 和向量 |_v_ ⟩ 的内积为 0 ，则称这两个向量正交 (orthogonal) 。比如，向量 |_u_ ⟩ ≡ (1, 0), |_v_ ⟩ ≡ (0, 1) ， 根据上面复向量空间内积的定义，可得 ⟨ _u_ ∣  _v_ ⟩ = 1×0 + 0×1 = 0 故 |_u_ ⟩ , |_v_ ⟩ 两向量正交。 向量 |_v_ ⟩ 的模 (norm) 定义为

‖|_v_ ⟩‖ : = √(⟨ _v_ ∣  _v_ ⟩)

​ 若向量 |_v_ ⟩ 满足 |_v_ ⟩| = 1 ，则称该向量为单位向量 (unit vector) 或归一化的 (normalized)。对于任意非零向量 |_u_ ⟩ ，可以通过将该向量除以它的范数得到其归一化形式，即：

(|_v_ ⟩)/( ∣ ∣ |_v_ ⟩ ∣ ∣ )

​ 设 |_b_ 1⟩, |_b_ 2⟩, ⋯, |_b_ _n_ ⟩ 为向量空间的一组基，满足每一个向量都是单位向量, 并且不同向量的内积为 0 , 即：

⟨ _b_ _i_ ∣  _b_ _j_ ⟩ = ⎧⎨⎩ 1,  _i_ =  _j_ 0,  _i_ ≠  _j_

​ 则称这组向量为向量空间的标准正交 (orthonormal) 基。 标准正交基能带来很多方便，比如在计算向量的内积时，就可以将向量的坐标对应相乘。 假设知道向量空间的一个非标准正交基 |_u_ 1⟩, |_u_ 2⟩, ⋯, |_u_ _n_ ⟩ ，那么，可以通过Gram-Schmidt正交化来将非标准正交基转化为标准正交基。具体过程如下， 用向量组 {|_v_ 1⟩, |_v_ 2⟩, ⋯, |_v_ _n_ ⟩} 来表示待生成的标准正交基, 首先定义

|_v_ 1⟩ : = (|_u_ 1⟩)/( ∣ ∣ |_u_ 1⟩ ∣ ∣ )

​ 接着对 1 ≤  _k_ ≤  _n_ − 1 ， 递归地计算并定义

|_v_ _k_ \+ 1⟩ : = (|_u_ _k_ \+ 1⟩ −  _k_ ∑ _i_ = 1⟨ _v_ _i_ |⟨ _u_ _k_ − 1| ∣  _v_ _i_ ⟩)/(‖|_u_ _k_ \+ 1⟩ −  _k_ ∑ _i_ = 1⟨ _v_ _i_ ∣  _u_ _k_ − 1⟩|_v_ _i_ ⟩‖)

​ 在量子计算中，通常，用一组带有指标 _i_ 的向量  ∣  _i_ ⟩ 来表示标准正交基。
