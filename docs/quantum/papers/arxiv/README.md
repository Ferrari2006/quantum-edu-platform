# arXiv Paper Notes

Use this directory for arXiv-derived metadata and internally written summaries.

First-batch policy:

- Import metadata, abstracts, authors, arXiv IDs, DOI, and source URLs through APIs.
- Do not download or locally store full-text PDFs by default.
- Check each paper license before full-text use.

Recommended metadata:

- `arxiv_id`
- `authors`
- `published`
- `updated`
- `primary_category`
- `categories`
- `abstract_source_url`
- `license`
- `retrieved_at`
