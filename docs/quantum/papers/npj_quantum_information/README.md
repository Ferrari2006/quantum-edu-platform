# npj Quantum Information Notes

Use this directory for open-access article metadata and internally written summaries.

Before importing full text, confirm the article's specific license.

First-batch policy:

- Use `link_only` or `approved_summary_only` by default.
- Check the license of each article individually.
- Only clearly reusable CC BY articles may be considered for local full-text copy.
- Do not locally copy or transform full text for CC BY-NC-ND articles.
