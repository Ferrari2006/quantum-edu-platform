# Introductory Quantum Computing Module

## Learning Goals

- Explain qubits using amplitudes and measurement probabilities.
- Apply basic gates: `X`, `Z`, `H`, and `CNOT`.
- Interpret simple statevector and measurement results.
- Prepare and recognize a Bell state.

## Suggested Sequence

1. Qubit state and normalization.
2. Measurement and Born rule.
3. Single-qubit gates.
4. Two-qubit systems and tensor products.
5. Entanglement and Bell states.
6. Simple Qiskit statevector examples.

## Exercises

- Compute the measurement probabilities of `( |0> - |1> ) / sqrt(2)`.
- Prepare a Bell state using `H` and `CNOT`.
- Explain why `Z` changes phase but may not change computational-basis probabilities.
